# Polytope of Ideas Stars

Interactive 3D stars from *The Polytope of Ideas* on [Michael's Memos](https://michaelsmemos.substack.com). Spin one, open a family, slice a spike.

| Star | Post | Live |
| --- | --- | --- |
| Robotics frontier: 42 territories in 7 families | Part 2 | https://michaelraspuzzi.github.io/robotics-star/ |
| Digital twin frontier: 54 territories in 7 families | Part 3 | https://michaelraspuzzi.github.io/robotics-star/digital-twin/ |

Each star is a single self-contained `index.html` (three.js from cdnjs), served by GitHub Pages from `main`. Section images for the digital twin star live in `digital-twin/img/` and are credited inside the star.
